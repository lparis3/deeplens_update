Using the simulation will require the GalaxiesML dataset. 
The paper explaining the dataset can be found [here](https://arxiv.org/abs/2410.00271v1), and the dataset itself can be found [here](https://zenodo.org/records/11117528). While the code was built up using the 127 x 127 cutout dataset, it can easily be modified to other cutout sizes (ELABORATE MORE ON LATER)
